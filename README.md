# ساخت نسخه‌ی اندروید سامانه‌ی کار و فناوری (با Capacitor)

## پیش‌نیازها (یک‌بار روی لپ‌تاپ نصب می‌کنید)
1. **Node.js** — از https://nodejs.org نسخه‌ی LTS رو دانلود و نصب کنید.
2. **Android Studio** — از https://developer.android.com/studio دانلود و نصب کنید.
   - بعد از نصب، یک‌بار Android Studio رو باز کنید و صبر کنید Android SDK رو خودش دانلود و نصب کنه (از تنظیمات اولیه‌ی همون برنامه).

## مراحل ساخت
1. پوشه‌ی `karvfan-android` (همینی که الان دارید) رو جایی روی سیستم‌تون قرار بدید.
2. یک ترمینال (Command Prompt یا PowerShell در ویندوز، Terminal در مک) باز کنید و به همین پوشه برید:
   ```
   cd مسیر/تا/karvfan-android
   ```
3. پکیج‌های لازم رو نصب کنید:
   ```
   npm install
   ```
4. پلتفرم اندروید رو اضافه کنید (این دستور یک پوشه‌ی جدید به اسم `android` می‌سازه):
   ```
   npx cap add android
   ```
5. آیکون و اسپلش‌اسکرین سفارشی رو خودکار برای همه‌ی سایزهای لازم بسازید (از روی فایل‌های `icon.png` و `splash.png` که کنار همین پروژه گذاشتم):
   ```
   npx @capacitor/assets generate --android
   ```
6. فایل‌های وب (`www/index.html`) رو داخل پروژه‌ی اندروید کپی/سینک کنید:
   ```
   npx cap sync
   ```
7. پروژه رو در Android Studio باز کنید:
   ```
   npx cap open android
   ```
8. داخل Android Studio صبر کنید تا Gradle sync تموم بشه (اولین بار ممکنه چند دقیقه طول بکشه).
9. از منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
10. وقتی تموم شد، یه لینک «locate» پایین صفحه میاد — فایل نهایی اینجاست:
    ```
    android/app/build/outputs/apk/debug/app-debug.apk
    ```
11. همین فایل APK رو به گوشی اندرویدی منتقل کنید و نصبش کنید (لازمه گزینه‌ی «نصب از منابع ناشناس» رو در تنظیمات گوشی فعال کنید).

## قابلیت‌های بومی اضافه‌شده
- **رنگ نوار وضعیت گوشی** هماهنگ با رنگ‌بندی سامانه — خودکار فعاله.
- **یادآوری تکالیف با نوتیفیکیشن** — وقتی دانش‌آموز وارد اپ می‌شه و تکلیفی با مهلت نزدیک داشته باشه، یه اعلان بومی گوشی هم (علاوه بر بنر داخل اپ) دریافت می‌کنه. این یادآوری فقط وقتی اپ باز می‌شه فعال می‌شه (نه در پس‌زمینه)؛ برای یادآوری واقعاً زمان‌بندی‌شده حتی وقتی اپ بسته‌ست، باید بعداً سرویس Firebase Cloud Messaging راه‌اندازی بشه (کار بزرگ‌تری‌ه و فعلاً پیاده نشده).

## نکات مهم
- این اپلیکیشن مثل قبل به اینترنت و به دیتابیس Supabase وصل می‌شه — یعنی گوشی موقع استفاده باید اینترنت داشته باشه (کاملاً آفلاین کار نمی‌کنه، چون داده‌ها روی سرور Supabase ذخیره می‌شن).
- اگه بعداً خواستید آیکون و اسم اپ رو سفارشی کنید، از ابزار `@capacitor/assets` استفاده کنید یا مستقیم فایل‌های داخل پوشه‌ی `android/app/src/main/res` رو عوض کنید.
- اگه خواستید نسخه‌ای بسازید که در Google Play قابل‌انتشار باشه (Signed Release)، به مستندات رسمی Capacitor برای «Signing Android apps» مراجعه کنید — این مرحله نیاز به گواهی امضا (keystore) داره.
- هر وقت محتوای `www/index.html` عوض شد (نسخه‌ی جدیدی که من می‌فرستم)، کافیه فایل رو جایگزین کنید و دوباره مرحله‌ی ۵ (`npx cap sync`) و ۸ رو تکرار کنید — نیازی به تکرار همه‌ی مراحل نیست.
